### renderTierPages

*function* — [`src/export/pack/repack.ts`](../../src/export/pack/repack.ts)

```ts
function renderTierPages(group: RepackedGroup, tier: number, pageSize: (page: AtlasPage) => {
    width: number;
    height: number;
}, loadPage: PageLoader): Promise<RgbaImage[]>
```

The pages of `group` at a tier above 1, from the members' higher-resolution
exports (never upscaled): the 1× layout scaled to the tier page size, each
region cut from the export at that tier. The regions are matched by name;
their trim may differ from the 1× export, so each is cut in original-image
space to the 1× trim rectangle. Pixels are in the group's alpha mode;
resampling is done premultiplied.

### TabulaProjectConfig

*interface* — [`src/export/config.ts`](../../src/export/config.ts)

Project settings.

| Member | Description |
|---|---|
| `format?: 'tbla' \| 'files'` | Output: `tbla` (default) packs the export into `.tbla` bundles, one per tier; `files` writes every file loose (inspect, debug). |
| `mode?: 'release' \| 'development'` | `release` (default): one bundle per load group and tier, skeletons repacked into the shared pages of `atlas.groups`. `development`: one bundle per asset and tier (swap one asset at a time), each asset with its own pages. |
| `images?: boolean` | Standalone images (PNG / WebP / JPG not used by an atlas, sprite sheet or font): exported as textures (default true). |
| `tiers?: number[]` | Resolution tiers to export, e.g. [2, 1, 0.5] (default [1]). Tiers above 1 need `<name>@2x` exports. |
| `ktx2?: BasisCodec \| 'none'` | KTX2 codec for atlas pages (default 'none'); per group / page in `atlas.groups`. |
| `ktx2Quality?: number` | UASTC level 0-4 (default 2) / ETC1S quality 1-255 (default 128). |
| `imageFormat?: PageImageFormat` | Page image format (default: webp when most source atlas pages are WebP, png otherwise). |
| `quality?: number` | Lossy WebP quality (default 90). |
| `atlas?: Pick<RepackGroupsFile, 'maxSize' \| 'padding' \| 'extrude' \| 'groups'>` | Atlas packing and co-draw groups (skeletons sharing pages). Default: one group. |
| `bake?: false \| { fps?: number; maxError?: number; tolerance?: number; }` | Baked animations (default on); false plays every animation live. |
| `loadGroups?: LoadGroupsSpec` | Load groups of the manifest. |
