### CurveData

*type* — [`src/core/types.ts`](../../../src/core/types.ts)

```ts
type CurveData = null | 'stepped' | number[] | Float32Array;
```

Curve between frame i and i+1: `null` = linear, `'stepped'`, or bezier control
points `[cx1, cy1, cx2, cy2]` per channel in absolute (time, value) units —
exactly as Spine 4.x exports them. Compiled skeletons store the control
points as views into the file buffer.

### CurveTimeline

*interface* — [`src/core/types.ts`](../../../src/core/types.ts)

A keyframed timeline with `channels` float values per frame.
Channel layouts: translate/scale/shear = x,y; rgba = r,g,b,a; rgb = r,g,b;
rgba2 = r,g,b,a,dr,dg,db; rgb2 = r,g,b,dr,dg,db; pathMix = rotate,x,y;
ik = mix,softness (+ stepped {@link CurveTimeline.flags}); transformMix =
rotate,x,y,scaleX,scaleY,shearY; physics* = one value (physicsMass: mass).

| Member | Description |
|---|---|
| `kind: CurveTimelineKind` |  |
| `target: number` | Bone, slot or path constraint index depending on `kind`. |
| `channels: number` |  |
| `times: Float32Array` |  |
| `values: Float32Array` | frameCount * channels values. |
| `curves: CurveData[]` | One entry per frame (the last one is unused). |
| `flags?: Uint8Array` | `ik` only, per frame (stepped): bit 0 = bend positive, bit 1 = compress, bit 2 = stretch. Physics timelines use `target` -1 for "all constraints with the global flag". |

*class* — [`src/core/animation-state.ts`](../../../src/core/animation-state.ts)

Plays animations on tracks with mixing and layering (spine-core
`AnimationState`). Call {@link update} then {@link apply} each frame,
then update the skeleton's world transforms ({@link Clip } does all of

const data = new AnimationStateData(skeletonData);

state.update(dt);

*function* — [`src/core/shaders.ts`](../../../src/core/shaders.ts)

```ts

```

Generate fragment shader with the specified max textures.
Uses if-chain for sampler selection (WebGL2-safe, same as Pixi v7).

The two-color tint formula from spine-webgl (verified):
gl_FragColor.a = texColor.a * v_light.a;
gl_FragColor.rgb = ((texColor.a - 1.0) * v_dark.a + 1.0 - texColor.rgb) * v_dark.rgb
                 + texColor.rgb * v_light.rgb;

With PMA (v_dark.a = 1.0), this simplifies to:
gl_FragColor.rgb = (texColor.a - texColor.rgb) * v_dark.rgb + texColor.rgb * v_light.rgb;

## `src/core/text/text-block.ts`

### SdfTextBlock

*class* — [`src/core/text/text-block.ts`](../../../src/core/text/text-block.ts)

```ts
class SdfTextBlock<TTexture = unknown>
```

Renderer-agnostic SDF text: text or number, style, layout and mesh with
dirty tracking: text, number and style changes relayout on the next

const block = new SdfTextBlock({ font, fontSize: 32, maxWidth: 300 });

const mesh = block.update(); // mesh.positions / mesh.words / mesh.vertexCount
